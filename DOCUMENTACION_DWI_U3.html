1. Capturas de Pantalla con el Funcionamiento del Sitio Web

2. Descripción de los Mecanismos de Seguridad Empleados

A continuación se describen los mecanismos de seguridad implementados en el proyecto para resguardar la confidencialidad, integridad y disponibilidad de los datos:

2.1 Autenticación por Middlewares y Hashing de Contraseñas con Bcrypt

  • Funcionamiento: Todas las rutas privadas están resguardadas mediante los middlewares auth y verified en routes/web.php. Si un visitante no autenticado intenta acceder directamente por URL a /curso, /crearcurso o /vistaperfil, el sistema bloquea el acceso y lo redirige a /login.
  • Resguardo de credenciales: Las contraseñas jamás se guardan en texto plano; se procesan con el algoritmo criptográfico Bcrypt (Hash::make()) y el campo password se declara dentro de la propiedad $hidden del modelo User para evitar su exposición en respuestas JSON.
CAPTURA 2.1 — Demostración de Autenticación y Hashing Bcrypt Haz clic en el botón, arrastra tu imagen aquí o selecciona el recuadro y presiona Ctrl+V
Figura 2.1: Protección de rutas mediante middleware auth y contraseñas cifradas con Bcrypt.

2.2 Cifrado Simétrico de Identificadores en URLs (Prevención de IDOR con Crypt AES-256-CBC)

  • Funcionamiento: En CrearcursoController, los identificadores de los cursos se cifran antes de enviarse al cliente mediante Crypt::encryptString($curso->id) utilizando cifrado simétrico AES-256-CBC autenticado con firma HMAC.
  • Protección: Cuando el usuario accede a /detallescurso/{id} o solicita eliminar un curso en /crearcurso/eliminarcurso/{id}, el servidor desencripta la cadena con Crypt::decryptString($id). Si un atacante modifica un solo carácter del hash en la URL, la firma falla y el sistema rechaza la petición con código 404 Not Found o 400 Bad Request.

Figura 2.2: Identificador de curso encriptado en la URL y bloqueo ante manipulación del parámetro.

2.3 Protección contra Falsificación de Peticiones en Sitios Cruzados (CSRF Token)

  • Funcionamiento: Todos los formularios y peticiones POST, PUT, PATCH y DELETE integran el token de seguridad @csrf (validado por el middleware VerifyCsrfToken) o la cabecera HTTP X-CSRF-TOKEN en peticiones AJAX. Si se envía una petición sin un token válido de la sesión activa, Laravel rechaza la solicitud con estado 419 Page Expired.

2.4 Enmascaramiento de Datos Financieros (Tarjetas y CVV) y Control de Propiedad (403 Forbidden)

  • Enmascaramiento de Tarjetas: En ProfileController@vistaperfil solo se envían a la vista los últimos 4 dígitos de la tarjeta (substr($card->numero_tarjeta, -4)). Además, en el modelo Tarjetas el atributo cvv está oculto en $hidden = ['cvv'] y al editar una tarjeta se devuelve enmascarado como "***".
  • Control de Acceso por Propietario: Tanto al editar/actualizar una tarjeta (if ($tarjeta->usuario_id !== Auth::id()) abort(403);) como al eliminar un curso (Curso::where('id', $id)->where('user_id', Auth::id())), el sistema verifica que el registro pertenezca estrictamente al usuario en sesión.

Figura 2.4: Ocultamiento de dígitos sensibles de tarjetas bancarias y validación de pertenencia.

2.5 Sanitización contra XSS (strip_tags), Prevención de SQL Injection y Subida Segura de Imágenes

  • Prevención de XSS y SQLi: Todas las entradas de texto en la creación de cursos se limpian con strip_tags() antes de almacenarse, las vistas Blade escapan automáticamente la salida con {{ }} y todas las consultas a MySQL se realizan con sentencias preparadas a través de Eloquent ORM.
  • Subida Segura de Archivos y Validación Backend: En CrearcursoController@registrar se valida que el archivo subido sea estrictamente una imagen válida (mimes:jpeg,png,jpg,webp|max:2048), se renombra con una cadena aleatoria de 32 caracteres (Str::random(32)) y se reprocesa con Intervention Image a 300x300 px para neutralizar cualquier carga útil maliciosa.

3. WEB Services de Terceros Empleados

El sistema integra el servicio web externo Open Exchange Rates API (ExchangeRate-API) a través de la clase de servicio App\Services\ExchangeRateService (app/Services/ExchangeRateService.php) para obtener tasas de cambio internacionales en tiempo real y ofrecer la conversión automática de los costos de los cursos desde Pesos Mexicanos (MXN) hacia USD, EUR, GBP, CAD y JPY.

5. Servidor de Aplicaciones

La plataforma Curso+ se despliega sobre una arquitectura de servidor de aplicaciones integrada por el stack XAMPP en Windows: Apache HTTP Server 2.4.58 como servidor web y puerta de enlace HTTP, el motor de ejecución PHP 8.2.12 (Zend Engine v4.2.12), el núcleo de aplicación Laravel 9.x mediante su Front Controller (public/index.php) y el motor de base de datos relacional MariaDB 10.4.32 (compatible con MySQL). Asimismo, soporta ejecución en modo de desarrollo local mediante php artisan serve.

Componente del Servidor Especificación y Configuración
Stack / Entorno de Despliegue XAMPP sobre Windows (C:\xampp\htdocs\MartinezCortezRauldeJesus_DWI_U3)
Servidor Web / HTTP Apache HTTP Server 2.4.58 (Win64) con módulos mod_rewrite, mod_headers y mod_expires
Motor de Ejecución (Runtime) PHP 8.2.12 (Zend Engine v4.2.12, ZTS x64) + Composer PSR-4 Autoloader
Framework / Núcleo HTTP Laravel 9.x (laravel/framework ^9.19), Front Controller public/index.php y App\Http\Kernel
Servidor de Base de Datos MariaDB 10.4.32 (compatible con MySQL), host 127.0.0.1, puerto 3306, BD proyectoalan
Sesiones, Caché y Bitácoras Driver file (SESSION_LIFETIME=120, http_only=true, same_site=lax), caché file y logs rotativos en storage/logs/
Servidor Embebido de Pruebas php artisan serve (http://127.0.0.1:8000)

5.1 Arquitectura del Servidor de Aplicaciones y Ciclo de Vida de la Petición

  • Recepción y Enrutamiento en Apache (.htaccess y public/.htaccess): El archivo .htaccess raíz redirige limpiamente las peticiones hacia /public/ sin exponer el código interno del framework, mientras que public/.htaccess enruta las solicitudes dinámicas hacia el Front Controller public/index.php mediante mod_rewrite.
  • Núcleo HTTP de Laravel (bootstrap/app.php y app/Http/Kernel.php): Inicializa el contenedor de dependencias y procesa cada solicitud mediante los middlewares globales (TrustProxies, HandleCors, ValidatePostSize, TrimStrings, SecurityHeaders, RequestSecurityLogger) y los grupos web (sesiones, cookies cifradas, CSRF) o api (throttle:api).
  • Procesamiento y Persistencia: Los controladores ejecutan la lógica de negocio, consultan la base de datos proyectoalan vía Eloquent ORM/PDO en MariaDB (127.0.0.1:3306) o consumen servicios externos vía HTTP Client, devolviendo vistas Blade o respuestas JSON estandarizadas.

5.2 Configuración, Endurecimiento y Optimización en Apache (.htaccess)

  • Bloqueo de archivos sensibles (FilesMatch y RedirectMatch): Deniega el acceso directo (403 Forbidden) a .env, composer.json, composer.lock, package.json, artisan, .editorconfig y repositorios .git.
  • Ocultamiento de información y navegación: Desactiva el listado de directorios (Options -MultiViews -Indexes), oculta la firma del servidor (ServerSignature Off) y remueve la cabecera X-Powered-By.
  • Cabeceras de seguridad a nivel servidor (mod_headers): Aplica X-Frame-Options: SAMEORIGIN, X-Content-Type-Options: nosniff, Referrer-Policy, X-XSS-Protection, Permissions-Policy y X-Permitted-Cross-Domain-Policies.
  • Caché de recursos estáticos (mod_expires): Establece expiración de 1 mes para archivos CSS, JavaScript e imágenes para optimizar el tiempo de carga.

5.3 Gestión de Entorno, Almacenamiento y Bitácoras del Servidor (.env, storage/ y config/logging.php)

  • Variables de entorno (.env): Centraliza la clave de cifrado APP_KEY, parámetros de conexión a MariaDB (127.0.0.1:3306, base de datos proyectoalan) y drivers de sesión y caché (file).
  • Enlace simbólico de almacenamiento (public/storage): Conecta storage/app/public mediante php artisan storage:link para servir las imágenes de portada de cursos (storage/images/).
  • Bitácoras rotativas (config/logging.php): Divide los registros del servidor en canales dedicados con retención diaria de 30 días: laravel.log (errores generales), auth.log (autenticación) y security.log (alertas de seguridad).
